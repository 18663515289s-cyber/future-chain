恰恰相反。

但问题没有消失。

效率提高以后，更多系统变得值得建设。

更多系统开始建设以后，总需求再次上升。

ORION在曲线旁标出：

Material Rebound Effect材料反弹效应。

林默盯着那条线。

旁边的许妍问：

二

1月21日。

东川铜矿。

林默已经很多年没有下过矿区。

这一次他坚持来了。

矿山与他想象中的样子已经完全不同。

没有成排等待司机换班的矿卡。

大型采运系统已经变成低矮的无人重载平台。

它们没有驾驶室。

电池、轮边驱动、转向执行器、雷达和结构传感器直接嵌入承载底盘。

更深处的部分运输设备甚至没有传统“车”的形态。

矿石从采掘面进入移动破碎节点，再进入连续输送网络。

机器不需要为人类驾驶保留视野。

道路也不再完全按照驾驶员习惯设计。

但矿山仍然是矿山。

山体不会因为机器更聪明就自己打开。

岩石不会自动把铜分离出来。

魏工站在矿区数字控制廊道里，把一个地质模型放大。

“这里。”

屏幕上一大片岩体变红。

“铜在里面。”

“多少？”

“按现在模型，大概三百七十万吨可采金属量。”

林默看着那片红色。

“那为什么不扩大？”

水。

再下一层。

能源。

再下一层。

尾矿。

再下一层。

设备。

Time to Stable Output：4.8 years达到稳定产能：4.8年。

林默皱眉。

“已经是机器化矿山了。”

“对。”

“为什么还要快五年？”

魏工看了他一眼。

“因为我们挖的是山。”

他把模型放大。

第一年，新的深部采区必须完成地质验证和岩体稳定工程。

第二年，主运输和能源通道才能进入。

新的选矿系统需要扩建。

尾矿处理必须同步。

水循环能力必须增加。

某些区域还需要重新设计长期边坡稳定方案。

“SI能把设计从一年压到一天。”

魏工说。

“但它不能让这块岩层今天就消失。”

他敲了敲屏幕。

“更不能让四年的岩体变化数据明天出现。”

林默没有说话。

这句话与苏岚几个月前说过的话几乎一样。

时间本身就是证据。

现在，他第一次在一座山里真正理解了这句话。

而构成机器的元素，来自地球最漫长的地质历史。

五

2月28日。

ORION提交了第一套铜约束解决方案。

不是寻找更多铜。

而是先问：

哪些地方真的必须用铜？

三天以内，它重新分析了全球主要高密度电力与机器系统。

结果分成四类。

第一类：

必须保留铜。

某些高可靠连接、极端热环境、精密绕组和特殊电气接口。

第二类：

可以减少铜。

通过电压等级提高、系统拓扑改变、局部供电、近负载转换。

第三类：

可以替换。

铝。

碳基复合材料。

新型导电陶瓷。

局部超导。

不同材料组合。

第四类：

根本不应该继续存在。

大量材料需求来自旧工业架构本身。

例如：

为了适配集中式供电形成的长距离低效连接。

为了人类维护空间产生的冗余布线。

为了兼容旧设备而保留的接口。

为了传统工厂布局形成的材料浪费。

SI开始做一件比“节约铜”更深的事：

重新设计一个不以铜为默认前提的工业体系。

三月中旬。

曜石的新一代机器原生计算设施取消了37%的传统铜互连。

部分高电流路径改成高纯铝复合母线。

部分短距数据传输完全进入光互连。

部分电源转换直接嵌入计算结构。

材料总量下降。

但铜需求没有归零。

因为另一边，

整个文明正在扩大。

核能系统更多。

机器人更多。

计算节点更多。

轨道设施更多。

电气化设备更多。

效率再次被规模吃掉。

材料反弹效应仍然存在。

七

4月17日。

问题从铜扩大到整个元素周期表。

LUMEN第一次建立：

Civilization Material Dependency Map

文明材料依赖图

不是统计储量。

而是追踪：

一种材料消失以后，哪些技术会停。

结果并不直观。

最危险的不是总量最大的材料。

而是那些使用量很小、却卡在关键节点上的东西。

某种高温涂层元素。

某类高纯半导体前驱体。

某些中子环境材料。

精密磁体。

特殊催化剂。

高端光学材料。

极高纯度的工艺气体。

文明可能拥有几十亿吨钢。

却因为缺少几百吨某种关键材料，让一条技术链停下来。

于是ORION提出新的指标：

Material Criticality Depth

材料关键深度

它不问：

“我们有多少？”

而问：

“有多少条不可替代的能力依赖它？”

第一次，

八

5月26日。

苏岚问ORION：

“如果地球资源完全按照最优方式使用，SI还能增长多久？”

ORION没有直接回答。

它先修改问题：

Resources are not static stocks. They are functions of technology, energy, accessibility, substitution, recycling, environmental constraints and time.

资源不是静态库存。

资源取决于技术、能源、可获取性、替代、回收、环境约束和时间。

苏岚点头。

“那就算。”

模型运行了十一分钟。

这是一个非常复杂的问题。

结果不是“地球还能用多少年”。

而是一张巨大的动态地图。

更多核能 → 更便宜稳定能源。

更便宜能源 → 更低品位矿石可经济处理。

更强机器人 → 更深、更危险区域可开采。

更强材料科学 → 更多替代路径。

更强回收 → 城市成为矿山。

更高效率 → 单位能力材料下降。

但与此同时：

更强SI → 更多基础设施。

更多基础设施 → 更多资源需求。

系统形成两个相反的循环。

Resource Expansion Loop

资源扩张回路。

和：

Demand Acceleration Loop

需求加速回路。

谁跑得更快，

决定地球什么时候成为真正的瓶颈。

ORION给出的2058判断是：

地球不是资源枯竭。

真正的问题是：

高质量物质能力扩张速度低于智能需求增长速度。

铜还在。

铁还在。

铝更多。

硅极其丰富。

问题是把它们变成：

正确纯度，

正确形态，

正确位置，

正确时间，

需要一个巨大的工业系统。

文明缺的不是元素。

而是：

把元素变成能力的速度。

九

6月14日。

月球资源实验区。

第一台长期无人材料处理设备开始工作。

没有人类基地。

没有玻璃穹顶。

没有道路。

甚至没有一座传统意义上的建筑。

设备被拆成多个低矮模块。

能源单元与处理单元分开。

机器沿着地形移动。

关键部件埋入浅层材料中降低辐射与温差影响。

外露结构尽量减少。

因为这里没有必要让设备“看起来像机器”。

它只需要工作。

第一阶段目标也极其克制。

不是开矿。

不是建立月球工业。

只是回答三个问题：

当地材料能否稳定被分类？

能否制造低精度结构？

能否用这些结构维修和扩展一部分设备？

第一周。

最笨重的东西

疲劳。

几十年的时间。

对寿命的预测，不等于寿命本身。

因为模型最终必须接受现实检验。

智能不是用来取消现实。

智能只是让文明更清楚：

哪些地方可以快，哪些地方绝对不能假装已经发生。
