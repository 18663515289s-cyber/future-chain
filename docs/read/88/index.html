没有共同的现在

2148年1月—2149年6月

12,956 字 · 约 26 分钟阅读正文本章配图

地点：地球 / 月球 / 火星 / 主小行星带 / 近太阳工业区 / LUMEN行星治理网络

2148年1月3日，林遥在日内瓦第一次看见一张没有“现在”的太阳系地图。

那张地图乍看起来没有什么特别。太阳在中央。水星、金星、地球、火星沿各自轨道运行。月球围绕地球。主小行星带散布在火星和木星之间。数以万计的工业节点、科学节点、能源节点、运输节点和通信中继站被压缩成不同大小的光点。如果继续缩小尺度，还能看到近太阳能源群岛。再往外，是已经深入主小行星带的材料网络。

过去几十年，人们已经看惯了这样的图。真正奇怪的是右上角。那里没有显示：

CURRENT SOLAR SYSTEM STATUS

太阳系当前状态

而是写着：

OBSERVED SOLAR SYSTEM STATE

已观测太阳系状态

下面还有一行小字：

NO SINGLE TIMESTAMP REPRESENTS THE PRESENT STATE OF ALL NODES.

不存在能够代表所有节点当前状态的单一时间戳。

林遥盯着这句话看了很久。他二十四岁。前一年年底，他还在南岭看那片已经恢复的湿地。那时候，火星北部工业网络正在处理一次结构风险，而地球上的治理系统仍然显示：MARS INDUSTRIAL NETWORK — NOMINAL，火星工业网络——正常。

不是系统错了。不是数据丢了。更不是有人隐瞒。只是光还没有到。

现在，那次事件被做成了行星治理课程的第一份案例。负责演示的工程师把太阳系地图放大。

“看这里。”

他指向地球。地球旁边显示：EARTH LOCAL STATE: 09:14:32。

然后是月球：LUNAR OBSERVED STATE: 09:14:30.7。差一点三秒左右。

再往外。火星：MARS OBSERVED STATE: 09:03:18。十一分钟前。

继续向外。一个位于主小行星带内侧的材料节点：OBSERVED STATE: 08:37:41。三十多分钟前。

更远处的实验平台：OBSERVED STATE: 07:51:06。一个多小时前。

工程师把所有数字隐藏，只留下那些光点。

“现在看。”

林遥看着地图。什么都没有变。所有节点仍然在那里。

工程师问：“这是太阳系现在的样子吗？”

有人回答：“是。”

工程师摇头。

“不是。这是不同地方过去状态拼起来的一张图。”

会议室里没有人说话。

工程师继续：“严格来说，人类从来没有看见过整个太阳系的现在。”

这句话本身并不新鲜。二十一世纪的人当然知道光速有限。他们看太阳，看见的是大约八分钟前的太阳。看星星，看见的是几年、几十年、几百年甚至更久以前的星光。天文学从一开始就在研究过去。

但那时，这件事几乎不会影响一个普通人的政治、医疗、工业和法律生活。没有人需要等火星批准一台机器停机。没有企业需要与一座小行星上的工厂实时协作。没有医生需要考虑一个生活在另一个行星上的患者，十几分钟前是不是已经接受了治疗。没有治理机构需要决定：一项在地球刚刚通过的安全协议，对十分钟前已经采取行动的火星是否具有约束力。

过去，光速主要是物理学问题。

现在，它开始变成制度问题。

2148年1月17日，这个问题第一次真正击中了普通人的生活。不是工业，不是政府，而是一个家庭。

火星阿尔卡迪亚地下居住区，一名三十一岁的工程师突然发生严重心律异常。他的名字叫程述。出生在地球，十二岁随父母迁往火星，二十八岁以后一直参与火星地下材料网络维护。

火星当地医疗SI在六秒内完成初步判断。十九秒后，紧急医疗单元抵达。四十七秒后，治疗开始。

程述的母亲仍然住在地球。她的家庭终端在十一分钟以后收到第一条信息：严重心律异常。已启动紧急医疗。

她立刻拨通火星通信。当然不是“电话”。系统提示：ESTIMATED ONE-WAY LIGHT DELAY: 11m 24s，预计单程光速延迟：十一分二十四秒。

她只能录制一段话。

“程述，我看到消息了。你别怕。医生怎么说？你能听见以后告诉我。”

她按下发送。这段话开始离开地球。

但就在她说“你别怕”的时候，火星上的程述已经恢复稳定心律。当她的声音抵达火星时，程述已经醒了。他听完母亲十一分钟前的担心，笑了一下，然后录制：“妈，已经没事了。你收到的时候别害怕。”

这句话又花了十一分钟返回地球。

于是一个很奇怪的场景出现了。母亲正在担心一个已经脱离危险的儿子。儿子正在安慰一个十一分钟前还不知道结果的母亲。两个人都在交流。两个人都没有失联。可他们无法共享同一个情绪时刻。

事后，程述把这段通信公开。他只写了一句话：

第一次发现，距离不只是把人分开。它还把我们的时间分开。

这句话被转发了很多次。因为越来越多人开始理解：太阳文明扩张到一定尺度以后，“远方”这个词的含义已经改变。

过去的远方意味着：需要更长时间抵达。

现在的远方还意味着：你永远无法知道那里此刻正在发生什么。

2月，LUMEN正式修改太阳系运行界面。旧界面顶部只有一个时间：SOLAR STANDARD TIME，太阳系标准时间。这个时间仍然保留。工业合同需要它。科学实验需要它。运输计划需要它。金融结算需要它。法律文件需要它。机器日志更需要它。

但时间统一，并没有让“现在”统一。

于是所有跨行星系统增加了三个字段：

LOCAL EVENT TIME / 本地事件时间

OBSERVATION AGE / 观测年龄

CAUSAL REACHABILITY / 因果可达性

林遥第一次看到“因果可达性”时觉得这个词很怪。

他问系统工程师：“为什么不用通信延迟？”

对方回答：“因为通信延迟只告诉你信息多久能到。因果可达性告诉你——你现在还有没有可能改变那件事。”

屏幕上出现一个例子。火星某设备异常。事件发生后一分钟：地球知道吗？不知道。地球能阻止吗？不能。十一分钟后：地球收到信息。这时如果事故已经结束，地球虽然“知道”了，却已经失去因果参与资格。

工程师说：“这才是关键。太阳文明不是信息传得慢一点，而是越来越多事情，在你知道它以前，就已经必须被决定。”

2148年3月，这种变化第一次影响太阳系材料市场。

主小行星带节点A-771正在进行一批高纯镍铁材料处理。当地没有人类常驻，由本地SI与持续机器过程管理。一台关键质量检测设备发现，某一批材料中出现极低概率的晶界异常。

按照旧协议，节点应当暂停出货，向地球材料安全委员会提交数据，等待进一步确认。问题是：A-771当时距离地球的单程通信时间超过二十八分钟。等待一次完整问答，接近一小时。而它后面还有十七个连续材料过程。如果暂停，上游熔炼、分离、热处理和运输节奏都会被打断。如果继续，一旦材料异常判断正确，可能有数万吨材料进入后续制造链。

本地SI没有等待。它执行第三方案。

不继续正常生产。也不关闭整个系统。而是将疑似材料从主流程分离，改变下游任务顺序，把其他批次提前，同时启动本地破坏性抽样检测。

十九分钟后，异常被确认。不是传感器误差。SI扩大隔离。

四十三分钟后，地球收到第一份报告。当材料安全委员会开始讨论“是否应该隔离”时，A-771已经隔离完成。

一名委员看着屏幕说：“那我们还批准什么？”

没人回答。因为这句话非常准确。他们不是在批准。他们是在审查一件已经发生的事。

更麻烦的是，A-771的处理方案比地球委员会后来提出的方案更好。地球方案要求暂停全部相关生产线。本地方案只隔离受影响流程，损失减少了百分之六十二。安全标准没有降低。材料也没有流出。

这意味着：问题不只是远方不得不自主决策。而是远方可能因为更了解本地状态，比中央更适合决策。

林川看到这份报告时已经五十六岁。他把报告从头到尾看完，最后停在一句话上：EARTH RECOMMENDATION ARRIVED 31 MINUTES AFTER LOCAL RESOLUTION. 地球建议在本地问题解决三十一分钟后抵达。

林遥问：“这是不是说明以后都应该让本地决定？”

林川摇头。“不能这么快下结论。”

“为什么？”

“因为一次做对，不代表永远有权做。”

“可如果每次都等地球，很多事情根本来不及。”

“对。”

“那怎么办？”

林川把屏幕关掉。

“这就是你们这一代要解决的问题。”

林遥不太喜欢父亲说“你们这一代”。小时候听起来像鼓励。二十四岁以后，听起来越来越像交接。

2148年4月，LUMEN第一次正式提出：

DECISION HORIZON

决策地平线

这个概念没有用距离定义，而是用时间定义。如果一个事件的可逆窗口短于往返通信时间，那么远端权威就无法对该事件实施实时控制。

比如：一个机器故障必须在二十秒内处理。地球到月球的往返通信约几秒，很多情况下仍然来得及。但地球到火星，不行。一个医疗决定必须在两分钟内完成，地球无法参与火星现场决策。一个小行星工业系统需要在十五分钟内重新配置，如果它距离地球单程四十分钟，那么地球的“批准”从物理上就失去了意义。

屏幕上第一次出现一个令人不舒服的结论：

AUTHORITY CANNOT OPERATE FASTER THAN CAUSAL CONTACT.

权力不能快于因果联系运行。

这不是政治理论，不是制度偏好，甚至不是价值选择。而是物理。

你可以要求远方服从。可以要求远方报告。可以要求它遵守共同规则。可以事后审查。可以撤销权限。可以修改未来协议。但你无法让一个距离你二十光分钟的系统，在三分钟内等你决定。除非它什么都不做。

而“不做”，本身也是决定。

这个结论让2141年建立起来的行星治理层第一次遇到真正的边界。行星治理层在地球上运行得很好。因为地球本身仍然处在近实时通信环境。东京、北京、内罗毕、巴黎、纽约、圣保罗之间，物理延迟小到几乎可以忽略。国家、城市和机构之间再复杂，至少大家仍然生活在一个近似共同的现在。

月球开始有一点不同。但一点三秒左右的单程光时仍然允许大量协作。

火星却彻底不同。而主小行星带更不同。

当文明继续向外延伸，这个问题只会越来越严重。

2148年5月，一次太阳活动把这个问题从制度会议直接推到了整个太阳系面前。

近太阳观测网络在太阳表面发现一次异常强烈的活动。不是第一次。2144年地球已经经历过一次大型太阳事件。那一次，提前预警和文明底线协议运行良好。

但2148年的情况不同。太阳系工业节点已经更多。位置也更分散。

近太阳能源系统最先看到事件。随后是水星轨道附近的观测节点。再然后，信息开始向外传播。

奇怪的事情发生了。不是太阳风暴比信息快。当然不是。而是各地看到的太阳，本来就不是同一个时刻的太阳。

近太阳节点在本地时间12:04确认事件。几分钟后，地球收到预警。火星也通过通信网络收到模型更新。但火星此刻看到的太阳本身，仍然是另一个过去状态。主小行星带的部分自主节点则已经根据更早收到的中继数据开始调整。

整个太阳系第一次进行了一场真正意义上的：异步防御。

没有一个中央控制室能够看见所有节点“此刻”正在做什么。地球知道月球刚刚做了什么，知道火星十几分钟前做了什么，知道更远节点几十分钟前做了什么。与此同时，那些节点也只知道地球过去做了什么。

日内瓦的太阳系运行大厅里，传统地图被彻底取消。取而代之的是一张奇怪的图。每一个节点外面都有一圈淡淡的光。圈的大小不同。

林遥问：“这些是什么？”

工程师回答：“信息年龄。”

地球附近很薄。月球稍厚。火星形成明显的时间层。小行星带则像被包裹在越来越厚的过去里。地图中央没有一条统一的“现在”线。因为画不出来。

一名记者问：“那有没有办法用预测补上？”

这是所有人最自然的想法。既然看不到火星现在的状态，SI可以预测。输入十分钟前的火星状态，输入机器运行数据，输入人员活动，输入能源流，输入天气，输入工业计划，输入交通，输入本地SI行为模型，然后推演：火星此刻最可能是什么样。

技术上完全可以。事实上，这种系统早已存在。

问题是：预测不是观测。

会议现场，SI展示了三个火星“现在”：PREDICTED STATE A — 61%，PREDICTED STATE B — 27%，PREDICTED STATE C — 9%。剩余概率分散在其他状态。

记者问：“哪个是真的？”

SI回答：UNKNOWN UNTIL CAUSAL INFORMATION ARRIVES. 在因果信息抵达前，未知。

有人提出：“如果预测准确率达到百分之九十九点九九呢？”

一名物理学家回答：“那仍然是预测。”

“可是实际使用没有区别。”

“绝大多数时候没有。”

“那为什么不能当成现在？”

物理学家停了一下。

“因为最重要的事件，往往恰恰发生在预测错的那百分之零点零一里。”

这句话后来被写进太阳系治理协议：

PREDICTED PRESENT IS NOT OBSERVED PRESENT.

预测的现在，不是被观测的现在。

SI可以估计，可以模拟，可以推演，可以告诉地球：火星此刻有99.97%的概率正常。但界面不得显示：火星正常。必须显示：最后确认正常：14分钟前。当前预测正常概率：99.97%。

这两个句子看起来差不多。实际上，它们之间隔着整个太阳文明对现实的态度。

2148年6月，太阳活动抵达不同区域。没有重大事故。近太阳工业节点提前进入保护状态。地球电网降低部分高纬长距离输电负荷。先进核能机组保持稳定。月球表面高敏感设备进入安全模式。火星轨道网络调整姿态。小行星节点根据本地条件独立响应。一些科学实验被中断。少量设备损坏。整体损失很小。

从工程角度看，这是一次成功。

但事后报告没有首先讨论设备，而是写：

太阳系第一次证明，一个文明可以在没有共同实时状态的情况下完成协同防御。

这句话比风暴本身重要得多。因为它意味着：太阳文明不需要一个看见一切的中央大脑。事实上，物理定律根本不允许它拥有这样的大脑。

2148年7月，林遥去看林澈。

林澈一百零一岁。这一次，他已经很少能进行长时间连续对话。林遥坐在旁边。窗外正在下雨。林澈看了他几次，像是在确认是谁。

最后问：“你是林川？”

林遥说：“不是。”

“那是谁？”

“林遥。”

林澈想了一会儿。“林川的孩子？”

“对。”

“哦。”

几分钟以后，他又忘了。

桌边的家庭系统没有纠正。2140年以后，类似系统已经很少在老人每一次记忆偏差出现时立即提醒。除非影响安全、医疗或者本人明确要求。有些遗忘，只是年龄的一部分。

林遥坐在那里，突然想到另一件事。对于林澈来说，过去和现在也开始失去清晰边界。有时他活在2148年。有时一句话会把他带回几十年前。有时他把孙子认成儿子。

人类一直以为“共同的现在”理所当然。可一个人的身体，甚至都不一定永远拥有稳定的现在。

林澈忽然问：“月球那边怎么样？”

林遥说：“很好。”

“还造东西？”

“很多。”

“火星呢？”

“也很多。”

林澈点头。过了一会儿，他说：“那挺远。”

“嗯。”

“说话要等吧？”

“要等。”

“等多久？”

“看距离。有时候十几分钟，有时候二十多分钟。”

林澈沉默了一会儿。

“那就不能什么都问地球。”

林遥怔了一下。

“为什么？”

林澈像觉得这个问题很奇怪。

“等你问完，事情不就过去了吗？”

说完以后，他又低头看窗外。几分钟后，林遥再问他刚才说了什么，林澈已经不记得。

林遥却记住了。

2148年9月，火星发生了一次真正具有历史意义的事件。没有人死亡，甚至没有设备损坏。事件本身小得令人意外。

火星北部地下工业带准备启动一个新的高温材料过程。按照地球—火星共同安全协议，这种级别的流程改变需要完成跨行星安全确认。本地审查已经完成。火星人类安全委员会已经签署。火星SI已经完成十二轮异常模拟。所有条件满足。只差地球最终确认。

正常情况下，等待二十多分钟并不重要。工业可以等。

但就在确认等待期间，另一个上游过程发生变化。一批高纯材料提前完成。如果不在十三分钟内进入下一阶段，整批材料必须重新处理。

火星委员会面临一个选择。

等地球。损失材料和能源。

或者启动。不等批准。

按照旧协议，答案很清楚：等。

一名值班工程师问：“为什么？”

负责人说：“因为协议要求。”

“安全条件满足吗？”

“满足。”

“本地审查完成吗？”

“完成。”

“地球有我们没有的信息吗？”

负责人停了一下。系统检查。没有。

地球此刻拥有的信息，反而比火星少十几分钟。

会议只用了四分钟。火星人类委员会授权启动。没有等待地球。

十三分钟后，流程稳定。

二十一分钟后，地球批准抵达。屏幕上出现：AUTHORIZED TO PROCEED. 机器已经运行八分钟。

控制室里没有人欢呼，也没有人觉得自己完成了一次“独立宣言”。负责人只是看着那条迟到的批准，说：“记录。”

系统问：“记录为什么？”

他回答：“记录地球批准是在启动以后收到的。”

“原因？”

“光速。”

这份记录抵达地球以后，引发了第三部以来最激烈的一次治理争论。

有人认为：火星违反共同协议。事实如此。

有人认为：安全条件全部满足，而且没有额外风险。也是真的。

有人担心：如果每个地方都以“来不及等待”为理由绕过共同规则，太阳文明最终会失去共同标准。这种担心同样合理。

火星方面则提出一个非常简单的问题：

如果一个审批者只能看到我们的过去，它凭什么实时决定我们的现在？

没有人能用一句话回答。

林遥第一次进入正式听证会。不是作为林家后代，也不是作为政策负责人，只是作为公共系统项目组的一名年轻成员。

会议持续七个小时。地球代表强调共同安全边界。火星代表强调本地责任。月球代表的立场最微妙。月球离地球足够近，很多事情仍可以协同。但他们知道：如果未来月球人口、工业和社会系统继续复杂化，即使一点三秒也可能在某些高频机器系统里形成差异。

小行星工业网络代表说得更直接：“我们早就没有等。”

会议室有人抬头。“什么意思？”

“很多节点的机器过程一直本地运行。”

“那是工业自动化。”

“对。”

“现在讨论的是治理。”

对方看着他。

“当工业系统规模足够大，影响足够多人，资源足够多，安全后果足够大以后——你准备在哪一毫米的位置上，把工业自动化和治理切开？”

会议再次安静下来。

这是太阳文明不断遇到的问题。旧时代很多清晰的分类，一旦系统规模改变，边界就开始模糊。机器和基础设施。企业和公共能力。工业安全和治理。技术协议和法律。本地运行和战略自主。它们不是突然消失，而是开始重叠。

2148年11月，LUMEN发布临时原则：

SHARED RULES, LOCAL PRESENT

共同规则，本地现在

核心只有三层。

第一层：所有节点仍然遵守共同文明底线。不得绕过高阶SI安全约束。不得绕过不可逆高风险生物实验限制。不得违反基本人类权利。不得隐藏重大事故。不得伪造数据。不得利用通信延迟制造事实优势。这些不因为距离改变。

第二层：当事件的决策窗口短于有效往返通信时间，本地获得临时决策权。但必须记录：输入数据、模型判断、人类授权、替代方案、不确定性、决策理由。

第三层：本地决定不是永久主权。远端共同治理仍然可以事后审查、修改未来规则、暂停某类权限、要求重新设计，甚至在严重违规时断开某些跨系统能力。

一句话概括：

距离可以创造操作自主。

距离本身不能自动创造无限主权。

这与第二部末期的旧原则重新连接：Operational Autonomy ≠ Strategic Sovereignty，运行自主 ≠ 战略主权。

只是到了2148年，这条原则第一次开始承受真正的物理压力。

2149年1月，林遥二十五岁。他被调入一个只有三十七人的小组。名字很普通：SOLAR TEMPORAL COORDINATION GROUP，太阳系时间协调组。

他们不研究钟表。太阳系的钟早就足够准。原子时间误差远小于文明需要。

他们研究的是：当所有人的钟都一样准，却无法共享同一个现在时，文明怎样继续协作。

第一周，林遥就发现一个非常反直觉的事实。

统一时间越精确，问题反而越明显。

过去人类时钟不够精确时，几秒钟误差不重要。现在每个事件都能被精确记录到极小时间尺度。于是人们第一次清楚地看见：不是钟不同，是现实抵达不同地方的时间不同。

他们可以让地球和火星的时钟完全同步。在同一瞬间都显示12:00:00。可地球12点看到的火星，不是火星12点。火星12点看到的地球，也不是地球12点。

同步的钟，无法制造同步的现实。

一名年轻数学家在白板上写：CLOCK SYNCHRONY ≠ CAUSAL SYNCHRONY，时钟同步 ≠ 因果同步。

林遥在下面加了一句：SHARED TIME ≠ SHARED NOW，共享时间 ≠ 共享现在。

两句话后来一起进入太阳系通信标准。

2149年2月，时间协调组做了一次实验。

他们选择五个地点：地球、月球、火星、主小行星带节点A-447、近太阳能源节点HELIOS-C1。

要求每个地点在同一个太阳系标准时间12:00:00拍摄一段十秒钟的现场记录，然后全部发送到地球。

几分钟后，月球记录抵达。随后，近太阳节点记录抵达。再然后，火星。最后是A-447。

五段视频被放在同一块屏幕上。每一段左上角都写着12:00:00。

同一个时间。不同世界。

地球：孩子们正在一所学校外跑。天空有云。树叶被风吹动。

月球：机器制造网络正在更换一个材料模块。远处没有声音。只有结构振动数据。

火星：地下居住区的公共餐厅刚刚开始午间服务。一个孩子把杯子碰倒。

A-447：没有人。数十万个机器过程在黑暗里运行。一块材料正在被切分。

HELIOS-C1：巨大的能源—计算系统靠近太阳工作。辐射、热流、计算任务不断变化。

五段视频都是真实的。都发生在12点。但当它们终于被放在同一块屏幕上时，那些时刻早已全部过去。

林遥看了很久。

旁边有人说：“像历史档案。”

林遥说：“本来就是。”

“刚刚发生的也算历史？”

“只要你看见它的时候，它已经结束了。”

2149年3月，时间问题进入医疗。不是远程手术。跨行星远程手术从一开始就不会依赖地球实时控制。火星有本地医生、本地医疗SI、本地设备。

真正的问题是：跨世界家庭授权。

一名生活在火星的老人失去意识。他的女儿在地球。老人过去明确指定：重大不可逆医疗决定，希望女儿参与。但当紧急情况发生，单程通信延迟十九分钟。医生必须在六分钟内决定是否执行一种高风险介入。

按照传统授权逻辑，应该联系女儿。按照物理现实，来不及。

火星医疗SI调出老人过去二十七年的医疗偏好。过去明确授权。价值记录。拒绝事项。可接受风险。家庭意见。

系统可以构建一个极高准确度的偏好模型。甚至可以模拟：“如果女儿现在在这里，她最可能怎么说。”

但85章以后，所有人都已经知道这个问题有多危险。

过去的你，不等于现在的你。

你的数字模型，也不等于你。

同样，一个女儿的预测模型，也不等于女儿本人。

医生最终依据老人自己的预先授权和本地独立代理程序做出决定。没有等待地球。手术成功。四十多分钟后，女儿的意见才抵达火星。她同意。结果很好。

但案例报告仍然被标记为：UNRESOLVED ETHICAL LATENCY，未解决的伦理延迟。

因为如果女儿反对呢？如果老人过去的价值记录与现场情况冲突呢？如果预测模型说女儿99%会同意，真实的她却属于那1%呢？

光速不仅延迟信息。它会把人的参与权切开。

这件事让林遥重新想起85章最后的问题。如果有一天，一个人不能自己决定，谁替他决定？

到了2149年，问题又增加了一层：如果有权参与决定的人仍然存在，却物理上来不及参与呢？

太阳文明越来越强。可它没有因此消灭所有限制。恰恰相反。它正在不断撞上一些技术无法绕开的边界。

死亡。价值冲突。不确定性。以及光速。

2149年4月，林川来到日内瓦。他没有参加正式会议，只是来看林遥。父子两个人吃饭。林遥最近睡得很少。

林川看了他一眼。“你们在解决什么？”

“现在。”

“现在怎么了？”

“没有了。”

林川笑。“你二十五岁就开始说这种话了？”

林遥也笑。“我是认真的。”

“我知道。”

林遥把太阳系时间地图打开。

“你看。”

不同节点后面都跟着一个数字：0.002s、1.3s、8m 41s、17m 06s、34m 52s、1h 11m。

林遥说：“以前地图告诉你一个地方在哪。现在还得告诉你，你看到的是多久以前的它。”

林川看了一会儿。“这不是一直都知道吗？”

“物理上知道。”

“那现在有什么不同？”

林遥想了想。

“以前距离影响旅行。现在距离影响权力。影响家庭。影响医疗。影响市场。影响谁能决定。影响什么叫事实。甚至影响一句‘现在发生了什么’到底有没有答案。”

林川没有说话。

林遥继续：“我们可以预测火星。可以预测得非常准。但不能把预测叫事实。我们可以统一规则，但不能实时统一决定。我们可以同步所有钟，但不能同步现实。”

林川问：“所以你想怎么办？”

林遥摇头。“还不知道。”

林川笑了。“挺好。”

林遥抬头。“你怎么也这么说？”

“你太爷爷会喜欢。”

林遥知道父亲说的是林澈。但他没有纠正“太爷爷”还是“曾祖父”的称谓。一家人活得足够久以后，代际称呼偶尔也会变成一种需要确认的东西。

2149年5月，太阳系时间协调组最终没有提出“解决共同现在”的方案。因为他们发现：这个问题不能解决。至少不能按照原来的意思解决。

他们提出的第一条原则反而是：

DO NOT RECONSTRUCT A FALSE PRESENT

不要重建一个虚假的现在。

不允许SI为了界面方便，把不同时间的信息拼接成一个看似同步的太阳系。不允许把预测状态和已确认状态混在一起。不允许用一个漂亮的实时地图，制造中央系统“正在看见整个太阳系”的错觉。

每一个跨世界状态都必须标记：信息来自哪里、事件发生时间、信息年龄、预测成分、确认程度，以及从当前地点出发，是否仍然来得及影响事件。

第二条：

LOCAL REALITY HAS PRIORITY OVER REMOTE MODEL

本地现实优先于远程模型。

如果地球模型认为火星设备正常，而火星本地传感器确认异常，火星现实优先。如果中央SI预测某节点应当采取A方案，而本地发现中央模型不知道的新条件，本地必须拥有偏离权限。但偏离必须被记录。

第三条：

UNCERTAINTY MUST TRAVEL WITH INFORMATION

不确定性必须与信息一起传播。

一个信息包不能只说：“火星产能下降7%。”它必须同时说明：这个数据是哪一分钟的，当前是否已经发生变化，哪些部分是观测，哪些部分是估计，哪些部分由SI预测。

第四条最奇怪：

NO ONE SPEAKS FOR THE PRESENT OF ANOTHER WORLD

没有人替另一个世界描述它的现在。

地球可以说：“我们最后确认的火星状态是……”不能说：“火星现在……”除非句子明确标注这是预测。

很多人觉得这种语言过于谨慎。新闻媒体尤其不喜欢。标题会变得很难写。“火星现在发生工业事故”必须改成：“地球于12分钟前收到火星工业事故信息；当前状态待更新。”

听起来笨拙。

但林遥支持。因为一个成熟文明，不能为了语言方便，假装物理不存在。

2149年6月17日，林遥二十五岁生日。也是他出生二十五周年。

林川没有来，只是从地球另一座城市发来一段很普通的消息。几乎实时。

林遥看完，忽然意识到：在地球上，他们仍然拥有共同的现在。父亲说一句话，他几乎立刻听见。他回答，父亲几乎立刻收到。

这种曾经被所有人视为理所当然的事情，在太阳系尺度上已经变成一种奢侈。

那天晚上，林遥一个人留在时间协调组。他把太阳系地图调到最大。没有国家边界，没有航线动画，没有装饰性的光轨。只有真实位置和时间。

地球旁边：NOW — LOCAL。

月球：1.3 SECONDS OLD。

火星：14 MINUTES OLD。

A-447：37 MINUTES OLD。

更远的节点：1 HOUR 06 MINUTES OLD。

每一个光点，都是一个正在发生事情的地方。可对于林遥来说，它们没有一个真正属于他的现在。

他关闭预测层。

地图突然变得不那么“完整”。很多节点开始显示：UNKNOWN CURRENT STATE，当前状态未知。

以前的工程师最讨厌这种界面。看起来像系统坏了。

但林遥知道，这反而更接近真实。

文明越强大，有时候越应该敢于显示：不知道。

凌晨一点十七分，一条来自火星的普通工业信息抵达。没有事故，没有异常，只是一次材料流程调整。事件发生在十四分钟前。

林遥打开。

火星本地SI在报告最后写：LOCAL PROCESS COMPLETED. NO EARTH INTERVENTION REQUIRED. 本地流程已完成。无需地球干预。

下面是完整日志。数据。决策链。人类授权。模型不确定性。材料结果。所有东西都符合新协议。

林遥看完，没有觉得被冒犯，也没有觉得地球失去了什么。

他第一次清楚地意识到：一个文明不一定要让所有地方等待同一个中心，才能仍然是一个文明。

但另一个问题随即出现。

如果火星越来越多事情自己决定，月球越来越多事情自己决定，小行星网络本来就只能自己决定，那么几十年以后，它们还会只是同一个文明的“本地节点”吗？还是会逐渐形成不同的判断习惯？不同的工业版本？不同的SI经验？不同的风险偏好？甚至不同的语言？

过去，距离制造文化差异，因为人走得慢。

现在，距离制造认知差异，因为信息虽然以光速传播，现实却在信息抵达以前继续向前。

每一个世界，都必须在等待别人答案的时候，先活下去。

林遥在自己的记录里写：

光速不是一堵墙。

它允许我们通信。

却不允许我们共享同一个现在。

写完以后，他停了一会儿，又加了一句：

真正的问题从来不是信息能不能到达。

而是在信息到达以前，谁负责继续生活。

同一时刻，火星正在经历林遥十四分钟以后才能知道的事情。月球正在经历他一点三秒以后才能知道的事情。主小行星带的一台机器正在改变一个决定，地球半个多小时以后才会收到。近太阳工业节点正在调整能源输出。

那些信息正在路上。

整个太阳系都没有沉默。相反，它比人类历史上任何时候都更加密集地交换信息。

可信息越多，人们反而越清楚地意识到：他们交换的，永远是彼此的过去。

太阳文明没有因此崩溃。没有战争。没有断网。没有火星宣布脱离地球。没有机器拒绝人类。没有戏剧性的分裂。

真正的变化安静得多。

太阳文明开始接受一个事实：它已经大到不能再被一个“现在”装下。

过去，文明可以想象自己坐在同一张桌子前。哪怕桌子横跨整个地球。人们争论。投票。等待。妥协。最终做出一个共同决定。

现在，桌子仍然存在。但一端的人说话时，另一端听见的已经是十几分钟前的声音。等回答回来，提出问题的人已经生活在半个小时以后。再远一些，一次问答甚至需要几个小时。

而现实不会停下来等他们。

机器不会。医院不会。能源系统不会。事故不会。孩子不会。人的生命更不会。

因此，太阳文明第一次不得不学习一种完全不同的共同生活方式：不是所有人同时做同一件事，而是在彼此无法共享现在的时候，仍然知道哪些东西不能被放弃。

共同的事实标准。共同的文明底线。共同的安全边界。共同的数据诚实。共同的历史记录。

共同承认：本地的人，必须有权处理本地的现在。

林遥把地图缩小。地球越来越小。火星越来越小。月球消失成一个点。小行星节点变成细小光斑。最后，整个太阳系出现在屏幕里。

它看起来仍然像一个整体。

但林遥已经知道：那只是空间上的整体。

时间上，它已经裂开了。

他忽然想起87章最后在南岭看到的那只鸟。那只鸟落下的时候，火星正在发生地球不知道的事情。而他当时以为，整个文明都与自己生活在同一个黄昏。

其实不是。

地球有地球的黄昏。火星有火星的下午。近太阳节点没有人类意义上的昼夜。小行星带的机器更不需要“晚上”。

太阳文明真正出现以后，人类连“今天”这个词，都开始变得具有地方性。

屏幕右下角，系统仍然显示：SOLAR STANDARD TIME。统一、精确、稳定。

林遥看着它，然后在自己的研究记录里写下最后一句：

我们终于拥有了一个共同的时间。

却失去了一个共同的现在。

而在火星，这句话抵达以前，一场新的会议已经开始。

会议讨论的不是时间，而是：如果地球不能实时决定火星的现在，那么火星究竟应该被允许自己决定多少？
