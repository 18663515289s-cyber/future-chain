第三种继承

公元2207年1月—2210年12月

710 字 · 约 2 分钟阅读正文本章配图

一、没有继承人的设施

公元2207年1月，外土星，深环工业区域。一座运行了八十七年的高精度制造设施，准备结束它的最后一项长期任务。设施编号D-41。它最初建成于2120年，承担过外土星早期工业扩展中的特殊材料加工、独立计量和紧急设备再制造任务。

二、第三种继承

2207年3月，地球。林遥八十二岁。他在自己的研究室里阅读D-41的历史资料。窗外是一片经过长期生态保护的城市公共林地。

三、一次没有人愿意签署的交接

公元2207年6月，深环。D-41的第一次公共责任协调会议，进行得并不顺利。参与者来自深环当前工业研究网络、弦石的相关制造谱系、远汐公共工业组织，以及几处仍然可能需要使用D-41恢复能力的外土星设施。

四、恢复一个已经不需要恢复的工厂

公元2208年2月，深环独立制造试验区。D-41的关键恢复能力验证，第一次在不依赖旧设施的条件下启动。

五、谁来决定什么值得留下

2208年11月，临川公共研究中心。一份关于D-41的成本评估，引发了新的争议。

六、关掉原来的路

公元2209年3月，深环。D-41主要任务退出后的第一次独立恢复演练正式开始。

七、保护文明的人，也可能替文明作决定

公元2209年9月，临川公共协调中心。D-41恢复演练完成之后，越来越多工业区域开始关注这项研究。

八、第一次主动撤销保护

公元2210年2月，深环。CCA的第一项有限实际应用，不是增加保护。而是撤销一项已经不再必要的历史保障。

九、文明不应该只有一个继承人

公元2210年8月，地球。林遥八十五岁。他与父亲林川坐在一间朝向林地的公共居住空间里。

十、没有祖先的明天

公元2210年12月31日，临川。许澄四十岁。距离她第一次进入第二代居住地，已经过去二十年。
