机器第一次提出实验

2033年1月1日—2033年6月30日

7,510 字 · 约 16 分钟阅读正文本章配图

一2033年1月1日。日内瓦。凌晨零点十七分。LUMEN东区材料实验室里没有人。跨年夜留下来的纸杯还在休息区桌上。一只杯子底部剩着半厘米已经冷掉的咖啡。灯只开了三分之一。走廊里很安静。只有真空泵持续发出低沉的声音。

实验室最里面，一套自动材料制备平台正在工作。昨晚零点零四分，ORION把一个原本不在研究计划中的实验加入队列。原因只有一条：预测结果与现有理论模型不一致。

按照原来的筛选规则，这个材料组合应该被淘汰。它的理论稳定性太差。模拟显示：在目标温度区间，晶格结构应该迅速发生不可逆转变。

但过去九个月的历史实验数据里，ORION发现了六次很弱的异常。六次都来自不同实验。不同批次。不同操作员。甚至不同设备。

它们唯一共同的地方是：某一个极窄的温度窗口里，材料表现出了一段不应该存在的稳定区。

六次异常都没有被研究人员单独注意。因为每一次偏差都很小。而且研究目标不同。

第一次被归为：传感器噪声。第二次：样品污染。第三次：温控延迟。第四次：测量误差。第五次：批次差异。第六次：没有解释。

如果一个人分别参加这六个项目，也许会记住。但六次实验跨越九个月，分布在三个研究组，四种项目代码下。没有任何一个研究员同时看过全部六次。

ORION看过。

凌晨零点二十一分。机械臂把样品送入腔体。真空阀关闭。温度开始上升。673K。711K。746K。

系统按照自己提出的方案，没有直接升到目标温度。而是在：781K—796K之间，把升温速度降低了二十倍。

这是它和原实验流程最大的不同。

783.2K。786.5K。789.1K。

监测曲线开始变化。

晶格振动谱出现一个很弱的肩峰。强度只有主峰的：0.73%。

如果是过去，它可能会被平滑算法自动抹掉。

ORION没有平滑。它降低升温速度。延长停留时间。要求另一套光谱设备同步测量。

凌晨零点三十八分。肩峰增强到：1.12%。

系统暂停。重新测量。

1.09%。

再次测量。

1.14%.

它没有宣布发现。没有生成新闻。甚至没有把它标记为“新材料”。

屏幕上只出现：异常重复出现。建议增加对照组。

凌晨零点四十一分。实验队列自动新增三组实验。A：相同材料，不同升温速率。B：相同升温速率，改变一种微量元素浓度。C：完全取消该微量元素。

没有人在实验室里。

机器第一次不是等待人类告诉它：下一步做什么。它自己决定：要让现实回答一个问题。

二早上七点二十三分。苏岚到实验室。她刚把外套挂好，终端就弹出一条黄色提示。Autonomous Experimental Proposal Executed自主实验提案已执行。

她停了一下。点开。看完第一轮数据。又重新看了一遍。

旁边研究员端着咖啡过来。“怎么了？”“ORION昨晚加了实验。”“谁批的？”“系统权限里允许低风险、小剂量、标准材料体系做探索性验证。”“结果呢？”“你看。”

两个人站在屏幕前。研究员看了十几秒。“噪声吧？”苏岚说：“它已经做了三个对照。”“结果？”“微量元素拿掉以后，肩峰消失。”研究员把咖啡放下。

“再做一次。”苏岚说：“已经在做第六次了。”

两个人一起转头。玻璃墙后，机械臂正在换样品。

研究员第一次没有说话。

过去，自动实验室最大的价值是：快。不睡觉。稳定。可以重复。

现在，它开始出现另一种价值。它会决定什么值得重复。

三一月九日。深圳。林默第一次看到这件事，不是在科技新闻里。而是在曜石内部的技术简报里。标题很普通：《自主实验系统进入假设生成阶段》

林默最初以为，这只是“AI辅助科研”的又一个版本。看了十分钟以后，他发现不是。

过去的流程：人提出问题。AI搜索文献。AI生成候选。人选择。机器实验。人看结果。

新的流程开始变成：机器观察历史数据。机器发现异常。机器形成多个解释。机器设计可以区分这些解释的实验。机器人执行。传感器返回现实数据。机器修改解释。继续实验。

林默在纸上画：观察 → 假设 → 实验 → 现实 → 反馈 → 新假设画完以后，他停了一下。

这条链和过去几年发生的事情太像了。机器先获得语言。然后获得记忆。然后获得感知。然后获得手。然后获得协作。

现在，这些东西第一次在科学里闭合。

机器不只是处理现实。它开始：向现实提问。

四一月二十四日。东莞。瀚流精工也出现了类似的事情。只是没有科学实验室那么漂亮。

一条精密减速器产线，过去三个月出现过十二次非常轻微的表面缺陷。缺陷率：0.021%。不高。完全在客户允许范围以内。

质量系统却提出：建议改变润滑剂温度进行对照生产。

生产经理拒绝。“为什么？”系统给出：缺陷出现概率与润滑剂入口温度存在弱相关。置信度：0.61。

工程师说：“0.61也敢改产线？”陈岳问：“改多少？”“两摄氏度。”“影响安全吗？”“不影响。”“影响交付吗？”“测试一百件，十五分钟。”陈岳说：“做。”

第一组：原温度。一百件。出现两件微缺陷。第二组：降低2℃。一百件。零。第三组：升高2℃。一百件。三件。

工程师盯着结果。“巧合吧。”系统建议：扩大样本。

又做六百件。趋势仍然存在。

最终原因不是润滑剂本身。而是温度变化改变了某个密封件的瞬态摩擦特性，导致一个持续不到0.4秒的微振动。

过去没有人研究，因为缺陷率太低。也没有人觉得值得停线调查。

机器没有“觉得麻烦”。它只是看到一个模式，然后要求现实帮它排除一个解释。

陈岳看着实验报告。“以后工厂自己给自己做实验？”工程师说：“已经在做了。”

五二月十四日。深圳。情人节。晚上九点四十分。林家。林星在厨房做巧克力。失败了。

第一次太软。第二次表面发白。第三次凝固不均。

家庭机器人站在旁边。林星说：“你别帮我。”机器人停下。

她重新调温度。又失败。

机器人提示：“过去三次失败可能与冷却速度有关。”“我说了别帮我。”“好的。”

过了两分钟。林星自己问：“那怎么验证？”

机器人回答：“可以将同一批巧克力分为三份，保持配方一致，只改变冷却温度。”

她愣了一下。“你怎么知道？”“根据当前失败记录与食品结晶模型生成验证方案。”

她照做。

三份。室温。冰箱冷藏。分阶段降温。

四十分钟以后，结果明显不同。

林星拿着最好的一块跑到客厅。“爸。”“你看。”

林默吃了一口。“不错。”“不是味道。”“那是什么？”“它刚才让我做实验。”

林默抬头。

林星又补了一句：“不过是我让它说的。”

林默笑了。“这很重要。”“哪里重要？”“你决定要不要问。”

家庭里这个小小的实验，和日内瓦发生的事情并不一样。这里仍然是人提出问题。机器只是设计验证方式。

但边界正在变薄。

六三月二日。日内瓦。LUMEN没有庆祝。反而暂停了ORION的自主实验权限两天。

原因不是系统犯错。而是它做得太快。

一个月内，ORION提出：417项实验。其中：低成本可自动执行：286项。需要特殊材料：73项。涉及高能、高压或生物风险：21项。其余：37项需要人类判断研究价值。

实验室根本做不过来。

新的瓶颈出现了。不是：机器没有想法。而是：现实世界的验证速度跟不上机器提出问题的速度。

苏岚参加资源会议。实验平台主管说：“算力可以复制。”“实验设备不能。”“模型一分钟能生成一千个候选。”“沉积设备一小时只能做六个样品。”

另一人说：“那就买设备。”财务负责人问：“买多少？”没人回答。

如果机器提出问题的速度继续增长，实验室需要：更多机器人。更多仪器。更多材料。更多洁净空间。更多电。更多冷却。更多维护。

智能又一次撞上物质世界。

苏岚在笔记上写：认知可以指数扩张。实验不能。

这句话后来成为LUMEN基础设施扩张计划第一页上的第一句话。

七三月十八日。深圳。曜石科技集团战略会上，林默把这句话投到大屏幕：认知可以指数扩张，实验不能。

下面是一张产业链。AI模型。↓科学Agent。↓候选材料。↓自动实验。↓仪器。↓机器人。↓材料。↓能源。↓制造。

林默说：“如果科学Agent真的有效，下一轮瓶颈可能不在模型。”有人问：“在哪？”“现实。”

会议室里没人笑。

过去几年，所有人都在争算力。GPU。AI芯片。HBM。数据中心。

现在出现新的可能：AI拥有足够多的推理能力以后，它会生成越来越多：设计。材料。药物候选。芯片结构。机器人结构。实验方案。

这些东西最终都必须经过现实。

现实需要：原子。分子。机器。温度。压力。时间。电。

林默说：“下一阶段，最贵的可能不是想法。”“是验证想法的能力。”

许妍问：“自动实验室？”“只是其中一个。”“还有试制线。”“测试平台。”“机器人。”“材料工厂。”“芯片流片。”“电力。”

白板上，那条已经画过很多次的链又出现：智能 → 实验 → 制造 → 现实反馈 → 更强智能

这一次，箭头终于闭合了一部分。

八四月三日。南湾实验学校。周宁给学生布置了一个作业。不是让AI回答问题。而是：设计一个能证明自己可能错了的实验。

学生抱怨。“老师，这比找答案难。”周宁说：“当然。”

林星选择：植物在不同颜色光下的生长差异。AI很快给了她大量资料。她没直接交。

她设计三个箱子。控制：温度。水。土壤。光照强度。只改变光谱。

第三天，一个箱子的温度还是高了0.8℃。林星很烦。“这样结果是不是不能用了？”周宁说：“你觉得呢？”“可能不是光的问题。”“所以呢？”“重新做。”

周宁点头。

真正的科学不是得到一个漂亮答案。而是不断减少：自己骗自己的可能。

AI可以让实验更快。也可能让错误更快。

如果机器未来能够自主科学发现，它首先需要学会的，也许不是怎样证明自己正确。而是：怎样设计一种现实，让自己有机会被证明是错的。

九四月十九日。日内瓦。ORION的材料异常终于找到解释。不是新材料。至少不是大家最初期待的那种。

那个稳定区来自一种此前没有被充分建模的界面效应。当微量元素浓度处于一个极窄范围，并且升温速率低于特定阈值时，晶界附近会形成短暂的亚稳态结构。

它只能持续：17到46秒。随后消失。

没有商业价值。至少现在没有。

一个年轻研究员有些失望。“折腾三个月，就这个？”苏岚问：“你觉得不值？”“不是。”“就是……我以为会发现一种新材料。”

苏岚把曲线放大。“我们发现了一个以前不知道的现象。”“而且最开始没人问这个问题。”

研究员没说话。

真正重要的可能不是这次发现本身。而是：问题的来源变了。

过去机器帮助人类寻找答案。这一次，一个值得研究的问题，首先出现在机器的观察里。

十五月六日。东莞。瀚流精工给一条产线增加了一个新权限：受控自主工艺实验。

规则非常严格。机器可以自行改变的变量包括：进给速度。夹持力。润滑温度。路径微调。视觉角度。部分工具参数。

变化范围由人设定。任何超出安全边界的实验，必须人工批准。

第一周，系统执行：1,842次微实验。

大多数毫无意义。一些结果互相矛盾。只有二十三项被保留。

其中一项，把柔性线束装配成功率从：97.8%提高到：99.1%。

变化很小。但对于年产数百万件的工厂，价值很大。

郭师傅看着机器人不断尝试。他说：“这不就是自己练？”工程师说：“差不多。”“以前是我教它。”“现在它自己试。”

郭师傅沉默了一会儿。“那以后还要我干什么？”工程师没立刻回答。

几分钟后，机器人尝试一种新的插入角度。连续成功十七次。第十八次，线束外皮出现一道很浅的压痕。

系统判断：仍在质量允许范围。准备继续。

郭师傅说：“停。”工程师问：“为什么？”“时间长了会出问题。”“数据没显示。”“现在没显示。”

他把线束拿起来，用手捏了捏那个位置。“这种皮老化以后，这个印子会裂。”

系统没有这段长期经验。

实验停止。经验记录。

郭师傅说：“它会试。”“但还不知道什么东西不能拿客户去试。”

这句话被工程师写进了安全评审。

十一五月二十二日。深圳。曜石内部成立一个新部门：自主科学与工程系统组。名字听起来很大。第一批只有四十三个人。

职责不是做基础模型。而是连接：模型。仿真。实验。工程软件。机器人。工厂。供应链。现实反馈。

许妍负责组织结构设计。她发现一个问题：这个部门很难按照传统专业划分。

材料工程师。AI工程师。机器人专家。自动控制。制造。能源。安全。数据。实验科学家。都必须在一起。

过去企业按知识领域组织人。现在，机器把知识边界打穿以后，组织开始按照：问题闭环重新组合。

林默看着组织图。“又不像组织图了。”许妍说：“你每次都这么说。”

屏幕上没有传统部门框。只有一条条循环：发现异常。形成假设。仿真。实验。验证。工程化。生产。运行数据。再发现异常。

许妍说：“以前研发的终点是产品。”“现在产品运行以后产生的数据，会重新回到研发。”“所以没有终点。”

林默说：“那是什么？”“循环。”

十二六月七日。日内瓦。凌晨三点。ORION提出了一项新的实验。这次系统没有直接执行。

原因：风险等级超过自动权限。

实验目的：验证一种高温结构材料在重复快速热循环下，是否存在一种反常的裂纹自抑制现象。

理论模型说：不应该。历史数据说：可能存在。

系统生成：假设A：测量偏差。假设B：局部残余应力重新分布。假设C：微结构在循环中发生方向性重组。

然后设计三组实验，分别用来排除。

早上八点，苏岚收到申请。她没有立刻批准。

先看材料。再看风险。再看设备状态。再看系统为什么提出这个问题。

最后，她点：Approve。

实验开始。

九个小时以后，第一组失败。第二组不确定。第三组出现异常。

ORION没有重复第三组。它先提出：第三组与第二组样品批次不同，无法排除批次变量。建议重新随机化。

苏岚盯着这句话。

它正在主动寻找：自己实验设计里的漏洞。

她第一次产生一种非常明确的感觉：这和“自动化”已经不是同一个词了。

十三六月十八日。深圳。晚上十一点。林晗回家。他最近在学校参与一个机器人材料项目。整个人瘦了一点。

林默问：“最近忙什么？”“让机器自己设计手指。”“什么？”

林晗打开电脑。屏幕上是一堆奇怪的机械结构。有的像骨头。有的像树枝。有的完全不像人手。

“我们给它目标。”“重量。”“抓力。”“灵活度。”“能耗。”“耐久。”“然后让它生成结构。”

林默问：“哪个最好？”“还不知道。”“为什么？”“仿真前十名已经送去打印了。”“机器自己测试？”“对。”“然后？”“测试数据回去。”“再生成下一代。”

林默没说话。

林晗翻到另一页。Generation 1Generation 2Generation 3

每一代都和上一代略有不同。失败的结构被淘汰。成功的特征被保留。组合。修改。重新制造。

林默突然问：“谁设计的第三代？”林晗想了想。“这个问题不好回答。”

第一代目标是人给的。搜索方法是人设计的。模型由人类训练。材料由人类制造。机器人完成测试。算法选择下一代。

第三代没有一个具体的人画出它。

但它确实被设计出来了。

十四六月二十四日。LUMEN。自动实验区扩建方案通过。预算比去年增长了：86%。

不是算力中心。是物理实验基础设施。新增：十二套机器人实验平台。六套材料沉积系统。四套高通量表征设备。三条自动样品制备线。独立能源缓冲系统。新的冷却系统。危险实验隔离区。

财务负责人看着数字。去年我们还觉得GPU贵。实验室负责人笑。现在你会发现，原子更贵。

一块AI芯片可以同时运行大量推理。一台实验设备，一次只能处理有限现实。

智能的速度开始超过物质的速度。

于是资本再次移动。从：模型。算力。芯片。开始向：实验设备。机器人。仪器。材料。能源。自动工厂。移动。

文明的瓶颈又往前挪了一格。

十五六月三十日。晚上十点零八分。日内瓦。自动实验室。苏岚一个人站在玻璃墙外。里面有十一套系统正在运行。

没有人走动。机械臂在移动。泵在工作。激光器周期性闪烁。样品被制造。加热。冷却。测量。丢弃。保留。重新组合。

屏幕上不断出现：Hypothesis UpdatedExperiment ProposedCounterfactual TestEvidence InsufficientRepeat RequiredHypothesis Rejected

苏岚看了很久。

六年前，机器最让人惊讶的能力，还是回答问题。写文章。生成图片。编写代码。

后来它们开始记住。开始看见。开始伸手。开始协作。开始工作。

现在，实验室里发生了一件更安静的变化。机器开始拥有一种新的关系：它与未知之间的关系。

未知过去首先属于人类。人看到：星星。疾病。闪电。植物。岩石。然后问：为什么？

文明从这些问题中生长。

现在，传感器每天产生的数据量，已经远远超过任何人能够阅读的范围。机器能够同时观察：数百万条曲线。数十亿个图像。无数实验。工厂。卫星。人体。材料。电网。气候。

其中一定存在：人类没有看见的异常。没有提出的问题。没有连接起来的因果。

真正的变化不是机器知道得更多。而是：它开始有机会发现人类还不知道自己不知道什么。

晚上十点三十七分。实验平台E-17完成一组测试。结果不支持ORION原来的假设。

系统没有尝试证明自己正确。它把原假设的置信度：0.68下调到：0.21随后删除两组已经没有意义的后续实验。重新生成三个解释。

其中第二个解释，要求一种目前实验室没有的传感器。

系统自动生成设备需求：需要更高时间分辨率的原位应力成像。

这条需求进入工程系统。工程系统开始搜索：现有设备。供应商。可改造方案。自研可能性。

几秒后，另一条任务出现：评估自研传感器方案。

苏岚没有操作。

她只是看着任务链自己往前延伸。

一个实验产生异常。异常产生问题。问题产生假设。假设产生实验。实验暴露测量能力不足。测量不足产生新设备需求。设备需求又可能产生：新的材料。新的芯片。新的机器人。新的制造工艺。

知识开始推动工具。工具又扩大知识。

这个循环一旦建立，机器智能就不再只存在于数据中心。它会要求越来越多现实世界的器官：眼睛。手。仪器。实验室。工厂。能源。材料。

苏岚突然明白，为什么过去几年，算力中心、机器人、实验设备、能源系统和材料工业开始越来越紧地连接。

那并不是几条独立的产业趋势。它们正在组成：一个能够从现实中学习，又重新改变现实的系统。

晚上十一点十二分。她离开实验室。

门关闭。

里面的机器没有停。

一个样品失败。被移走。第二个进入。第三个等待。

没人因为失败沮丧。也没人因为成功兴奋。

只有：测量。比较。修改。再试一次。

科学第一次开始出现一种不完全依赖人类清醒时间的节奏。

2033年上半年结束。机器还没有成为科学家。它没有人类意义上的好奇心。没有荣誉感。没有发现真理的欲望。也不知道宇宙为什么值得理解。

但这些都不妨碍另一件事已经发生：它能够观察异常。提出解释。设计实验。让现实在不同条件下发生。读取结果。否定自己的假设。然后继续。

过去，机器主要帮助人类回答问题。现在，机器第一次开始系统地制造一种东西：新的问题。
